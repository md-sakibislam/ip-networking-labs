# IP Networking Labs

Hands-on networking labs built and verified using Cisco Packet Tracer.

The purpose of this repository is to document practical experience with Layer 2 and Layer 3 networking, routing, troubleshooting, and network verification.

## Lab Documentation

Each completed lab contains:

* `README.md` — objective, topology, addressing, configuration, verification and lessons learned
* `topology.png` — network topology
* `configs/` — relevant device configurations
* `verification/` — command output and connectivity tests
* `.pkt` — Cisco Packet Tracer project

## Platforms

* Cisco Packet Tracer
* GNS3 for selected routing experiments

## Approach

The labs focus on building small working networks, verifying their behavior, documenting the configurations, and understanding the underlying networking concepts.
